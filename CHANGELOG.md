# Changelog

## Version 1.0.42

- Fixed native sitemap HTTP 501 errors on hosts without SimpleXML by adding an escaped XML serializer for the existing WordPress sitemap renderer.
- Retained native sitemap URLs, providers, pagination, stylesheet filters, visibility settings, and the legacy sitemap redirect.
- Kept SEO-plugin/custom-renderer ownership and the normal renderer when SimpleXML is available.
- No homepage, header/footer, menus, content setup, CSS or JavaScript changes.

## Version 1.0.41

- Packaged the cumulative Phase 1 and Phase 2 theme for live-site updating.
- Added live update, page initialization, homepage preservation and rollback instructions.
- Release metadata and documentation only; frontend templates, assets and page setup behavior are unchanged from 1.0.40.

## Version 1.0.40

- Enhanced 16 existing service destinations with one reusable service experience, preserving their URLs and saved content.
- Added call/demo/quotation actions, scoped responsive feature cards, contextual related links and a mobile action area.
- Added a consent-gated browser-only enquiry composer using existing WhatsApp/email destinations; no new lead database, submission endpoint or CRM was introduced.
- Added a native Locations directory and one Andhra Pradesh coverage page, with no automatically generated city pages or unverified office claims.
- Extended existing internal SEO context and connected schema with service titles, consistent breadcrumbs and directory ItemLists.
- Added an SEO & Enquiries tab to the existing theme dashboard with live local inventory and clearly unavailable external metrics.
- Preserved homepage output, shared assets and public navigation; retained Phase 1 safeguards and tests.

## Version 1.0.39

- Added an editable Software Solutions hub and missing education, accounting, sales/POS, task management and WhatsApp integration topics using native WordPress pages.
- Centralized internal-page business contact data through existing Theme Options.
- Added factual, connected internal-page schema and improved canonical, social and description output while yielding to supported SEO plugins.
- Removed unsupported product ratings and visitor-facing keyword panels.
- Integrated virtual offerings into WordPress's paginated sitemap and retained the legacy sitemap URL through a redirect.
- Corrected virtual-route query states and limited offering rewrites to known slugs.
- Added crawlable blog pagination and corrected main landmarks in the affected internal templates.
- Preserved homepage templates, shared CSS/JavaScript, header, footer and primary menus.
- Added disposable-WordPress integration and read-only localhost HTTP checks.

## Version 1.0.0

- Initial commercial theme foundation.
- Added premium homepage sections, Customizer options, native CPTs, secure demo importer, schema output, breadcrumbs, compatibility styling, documentation, and final QA assets.
