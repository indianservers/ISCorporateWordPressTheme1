Update Indian Servers Corp Pro to 1.0.42

4 November 2026. This package contains the cumulative Phase 1 and Phase 2 implementation. Version 1.0.42 fixes native sitemap HTTP 501 errors on hosts without SimpleXML. It uses the existing WordPress providers and sitemap routes with a safe XML serializer when the normal serializer cannot run. Homepage presentation and page setup remain unchanged.

Update the existing iscp theme in place. Keep the current homepage assignment, active child theme (if any), menus and Customizer settings. Do not run Demo Import, reset theme settings or assign Software Solutions as the homepage.

Before updating

  1. Confirm the live parent theme is Indian Servers Corp Pro, folder iscp. If a child theme is active, keep it active. This ZIP is an update for ISCP, not a migration from a different live theme.
  2. Back up the live database and the complete installed theme folder using the existing hosting/backup system. Confirm how to restore that backup. The local development backup is not a backup of the live database.
  3. Record desktop/mobile homepage screenshots, the active theme, menu assignments and current Settings → Reading values. Save the homepage and posts-page selections without changing them. Record existing Customizer settings if the hosting backup does not include them.
  4. If files inside the live parent theme were edited directly, compare and preserve those edits before replacement. A theme upload replaces files. The packaged homepage/shared files were verified unchanged in this project, but uninspected live-only edits cannot be guaranteed to match.
  5. Use a staging copy first when available. Review the generated pages and enquiry behavior there before applying the same update live.

Upload the ZIP

  1. Log in as an administrator. Open Appearance → Themes → Add New Theme (or Add New) → Upload Theme.
  2. Select iscp-1.0.42.zip and click Install Now. The ZIP contains one iscp/ folder; do not unzip and upload individual files through the theme editor.
  3. When WordPress detects the installed theme, select Replace current with uploaded. Confirm the uploaded theme/version is Indian Servers Corp Pro 1.0.42. Do not delete the active theme first.
  4. Keep the existing theme or child theme active. Updating the active parent does not require switching to another theme or activating the parent over an active child.

The replacement action is described in WordPress's theme-upload instructions. Reading settings determine homepage/posts-page assignments; leave the live site's current values intact.

Initialize and review the pages

  1. Visit Dashboard → Home once as an administrator with permission to publish pages. The theme runs the Phase 1 and Phase 2 page setup automatically, once per setup version.
  2. Open Pages → All Pages. Review /software-solutions/, /locations/, /locations/andhra-pradesh/ and the missing software topics created during Phase 1. Check the earlier implementation reports for the full page map.
  3. Setup publishes newly created starter pages, reuses matching existing pages and leaves owner drafts/private content unchanged. Review and publish a reused draft manually only if it should be public. Existing aliases can retain different URLs.
  4. No separate template activation is needed for newly created pages: their default WordPress template and the existing offering routes load the enhanced components. Existing product/service URLs remain in place.
  5. Open Appearance → Indian Servers Corp Pro → SEO & Enquiries to inspect the actual service destinations and location status. A protected/unpublished existing Locations parent can block regional setup; resolve it only according to the intended privacy/publication policy.
  6. If setup already ran in 1.0.39/1.0.40, updating to 1.0.42 does not recreate pages deliberately removed later or overwrite edited content. Do not reset setup options or run Demo Import to recreate them. Investigate the page list/status before requesting a targeted repair.

Verify without changing the homepage

  1. Open the homepage in a private browser window at desktop and mobile widths and compare it with the saved screenshots. Check navigation, hero, footer and contact shortcuts. Keep Settings → Reading, menus and global design settings unchanged.
  2. Check the software directory, one school/college page, one business-software page and the Andhra Pradesh page. Verify the primary call link is tel:+919618222220 and review the existing saved Contact settings if the displayed phone differs.
  3. If a new URL returns 404, open Settings → Permalinks and click Save Changes without changing the permalink structure. Existing rewrite rules also refresh automatically for the theme's route version.
  4. Clear the existing WordPress/hosting/CDN cache through its normal controls, then check again. Do not disable working plugins or install a duplicate SEO plugin.
  5. Check /wp-sitemap.xml, or the configured SEO plugin's sitemap, and the legacy sitemap URL. A physical server-root sitemap can override WordPress; its production handling needs a hosting check.
  6. Confirm titles, canonicals and schema with the actual SEO plugin, and check that public pages are indexable. Noindex settings are not automatically removed by setup.
  7. Test enquiry preparation using non-sensitive example data. Consent and validation are required. Preparing a message opens no submission: the visitor reviews and sends it through WhatsApp/email. Use the established inbox to confirm receipt of a deliberately authorized real test if needed.

Verify the SimpleXML-free sitemap fix

After installing 1.0.42, clear the existing site/CDN cache and open /wp-sitemap.xml. It should return XML with HTTP 200, including links to child sitemaps. Open at least one native pages sitemap and the iscpofferings sitemap. The old /sitemap.xml URL still redirects to the native index. No PHP extension installation or robots.txt change is required for this fallback. Supported SEO plugins and custom sitemap renderers keep ownership of their output.

Local validation covered 15 assertions with normal SimpleXML and 15 with SimpleXML classes/functions disabled, plus 49 HTTP/XML checks across the index, five child sitemaps, XSL stylesheets, invalid routes, the legacy redirect, robots reference and unchanged homepage HTML. Live results require uploading this release first.

Rollback

If the live homepage or functionality changes unexpectedly, restore the backed-up theme and, when appropriate, the database through the established backup workflow. Do not try to restore the old homepage by assigning Software Solutions or changing Reading settings. Newly created native pages may remain after a file-only rollback; review them individually and never delete reused owner pages.

Source checks confirmed that the homepage template, header/footer, homepage sections/cards, shared main stylesheet and pre-existing JavaScript are unchanged. Production installation, cache behavior, live-only edits and external account configuration still require the checks above.
