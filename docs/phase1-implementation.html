Indian Servers Corp Pro 1.0.39 · 4 November 2026

Implemented in the theme source and tested in an isolated local WordPress installation. Production deployment, installed production plugins and hosting policies were not accessible. Homepage presentation and primary navigation were preserved. Phase 2 has not started.

Existing functionality reused

  • Classic PHP theme templates, design tokens, existing product/service catalog and virtual URLs.
  • Native WordPress pages, page editor, excerpts, existing Contact Customizer section and demo-request dialog.
  • Existing SEO-plugin detection for Yoast, Rank Math and AIOSEO. No SEO plugin was installed.
  • Existing SEO entry points now use a factual internal-page graph and yield to supported SEO plugins.
  • WordPress's native paginated XML sitemap, extended with public virtual routes.

The internal graph connects Organization, WebSite, WebPage, BreadcrumbList and the relevant Service or SoftwareApplication. It uses the shared telephone and the owner-provided Andhra Pradesh service area. It does not invent an address, legal name, employee count, review, rating or price. LocalBusiness and automatic FAQ markup are omitted where verified supporting details are unavailable. SoftwareApplication markup does not imply Google software rich-result eligibility.

New topic pages discuss workflows to scope with the business; they do not promise every listed integration or module is already included in a ready-made product. WhatsApp copy makes no Meta-partner claim or account-approval/delivery guarantee.

Deployment and live checks

  1. Back up the production database and theme, then install the updated theme. A source backup for this session is at %TEMP%/iscp-phase1-20261104/iscp-before-phase1.zip, with a baseline SHA-256 manifest beside it. No production database was available to back up.
  2. Visit the dashboard as an administrator. Review the ten created/reused pages in Pages. Edit the native title, content and excerpt as required; the setup will not overwrite later edits.
  3. Review the existing Contact settings. Supplied defaults are +91 9618222220, tel:+919618222220 and the existing WhatsApp number. Existing owner-saved values remain authoritative.
  4. Verify the actual active theme/child theme, installed SEO/security/cache plugins, Reading settings, permalink structure, redirects and indexability. Their production configuration is not part of this repository.
  5. If a supported SEO plugin is active, inspect its virtual-route titles, canonicals, schema and sitemap coverage. The theme yields to it; these integrations were guard-tested, not tested against a configured production SEO plugin.
  6. Verify /wp-sitemap.xml and the legacy sitemap URL. A static server-root sitemap.xml exists in the parent project; a web server may serve it before WordPress. Review that separately rather than silently deleting it.
  7. Validate deployed pages with Google's Rich Results Test and Schema.org validator, and use Search Console URL Inspection. Local JSON parsing and structural checks are not a claim of external rich-result approval.
  8. Confirm crawler access in live robots.txt, CDN/firewall/security policies and server logs. The public production robots and native sitemap could not be retrieved through the web tool in this session. No production crawler-access conclusion is inferred from that failure.
  9. Clear the existing site cache through its normal workflow, compare the production homepage at desktop/mobile sizes, and verify real forms, call links and enquiry handoff without sending unsolicited test messages.

Rollback: restore the source backup. Native pages created by this release remain ordinary WordPress pages; inspect the iscp_software_page_ids option or page list and move only unwanted newly created pages to Trash. Never delete reused owner pages. Resetting the theme does not erase content or contact settings.

Crawler policy and sources

No robots.txt, CDN rule, model-training permission or llms.txt was changed. Search and training access are treated separately. Official references reviewed:

  • Google: AI features and your website — ordinary search eligibility, useful visible content and accurate structured data.
  • OpenAI crawler documentation — OAI-SearchBot is distinct from training-oriented access.
  • Anthropic crawler documentation — Claude-SearchBot, Claude-User and ClaudeBot have different roles.
  • Google: SoftwareApplication structured data — supported rich-result requirements must not be met with fabricated ratings or prices.
